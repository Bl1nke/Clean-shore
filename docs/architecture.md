# Минимальная структура сайта

## Экранный путь

`/login` -> `/dashboard` -> `profile`, `map` или `tiktok`.

## Страницы

| Страница | Шаблон | Назначение |
| --- | --- | --- |
| Вход | `templates/auth/login.html` | Начальный экран авторизации. |
| Главная панель | `templates/dashboard/index.html` | Содержит будущие кнопки перехода. |
| Профиль | `templates/profile/index.html` | Экран данных пользователя. |
| Карта | `templates/map/index.html` | Экран карты. |
| TikTok | `templates/tiktok/index.html` | Экран ссылки или встроенного контента TikTok. |

Каждая страница имеет собственный модуль с `routes.py`; в текущем каркасе это только места для будущих маршрутов. Обработчики, авторизация, ссылки и интеграция TikTok намеренно не реализованы.
