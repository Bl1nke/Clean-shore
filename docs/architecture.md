# Минимальная структура сайта

## Экранный путь

`/login` -> `/dashboard` -> `profile`, `map` или `learning`.

## Страницы

| Страница | Шаблон | Назначение |
| --- | --- | --- |
| Вход | `templates/auth/login.html` | Начальный экран авторизации. |
| Главная панель | `templates/dashboard/index.html` | Содержит будущие кнопки перехода. |
| Профиль | `templates/profile/index.html` | Экран данных пользователя. |
| Карта | `templates/map/index.html` | Экран карты. |
| Обучение | `templates/learning/index.html` | Будущий экран обучающих материалов. |

Каждая страница имеет собственный модуль с `routes.py`; в текущем каркасе это только места для будущих маршрутов. Обработчики, авторизация и содержимое обучения намеренно не реализованы.

## Стили

Все CSS-правила сайта хранятся в едином файле `app/static/css/styles.css`. Для текущего небольшого количества страниц это упрощает поддержку единого дизайна. Когда проект существенно вырастет, файл можно будет разделить по компонентам или страницам.
