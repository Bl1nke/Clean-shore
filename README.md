# Чистый берег

Минимальный каркас сайта на Python и HTML/CSS.

## Страницы

- Вход.
- Главная панель.
- Профиль.
- Карта.
- Обучение.

На главной панели будут три кнопки: «Профиль», «Карта» и «Обучение». Сейчас проект содержит только папки и пустые заготовки страниц, без логики, маршрутов, ссылок и дизайна.

Схема расположения файлов: [docs/architecture.md](docs/architecture.md).
